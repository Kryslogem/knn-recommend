# NFR01 benchmark: Top-10 recommendation latency

Target (NFR01): Top-10 in about 2 seconds once the model is loaded. **Result: MET** (p95 = 69.9 ms).

## Method
- Endpoint: `GET /admin/recommendations/movielens/{id}?n=10` over real HTTP to `http://127.0.0.1:8000` (uncached; same fold-in path as a web user).
- 300 distinct MovieLens profiles drawn at random (seed 0), after 5 warm-up requests; profiles had 14 to 479 rated films (median 50).
- Active model: `knnbaseline-20261110-100639-5962b10f`.
- Client and server ran on the same machine, so network latency is negligible. Includes DB read, fold-in against all 943 training users, Top-10, enrichment and JSON.

## Results (milliseconds)
| Measure | p50 | p95 | max |
|---|---:|---:|---:|
| End-to-end (client-timed) | 49.8 | 69.9 | 146.6 |
| Fold-in + ranking only (server-reported) | 32.2 | 41.5 | 108.9 |

p99 end-to-end: 75.6 ms.
