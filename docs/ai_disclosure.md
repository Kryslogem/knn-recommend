# Khai báo sử dụng Generative AI

| Công cụ | Dùng cho | Phạm vi | Cách nhóm kiểm chứng |
|---|---|---|---|
| ChatGPT | Soạn đặc tả ban đầu (`README.md`, `desc.md`) | Tài liệu | Đối chiếu rubric, nhóm tự chỉnh sửa |
| Claude (Claude Code) | Lập `PLAN.md`; dựng khung dự án giai đoạn 0 | Tài liệu, cấu trúc mã | Chạy thử lệnh, review mã |
| | | | |

Cập nhật bảng này mỗi khi dùng AI cho mã nguồn, phân tích hoặc báo cáo. Mọi kết quả thực nghiệm phải do nhóm tự chạy; AI không được dùng để tạo số liệu.
